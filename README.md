# GMaps-Test
Proyecto de prueba con **Google Maps API** integrado en una aplicación web.  
El objetivo es mostrar un mapa interactivo con marcadores utilizando coordenadas de ejemplo, manteniendo la clave de API protegida mediante **Node.js, Express y dotenv**.

## ▶️ Instalación y ejecución
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/mdanielagtz/GMaps-Test.git

2. Instalar dependencias:
   ```bash
   npm install

3. Crear archivo .env en la raiz con tu API_KEY
    ```bash
API_KEY=tu_api_key_aqui

4. Ejecutar el servidor
   ```bash
   node server.js

5. Abrir en el navegador
   ```bash
   http://localhost:3000
